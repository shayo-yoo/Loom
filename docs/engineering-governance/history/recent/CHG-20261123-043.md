# CHG-20261123-043

- Date: 2026-11-23 (Asia/Shanghai)
- Type: FEATURE, API, TEST, DOCS
- Requirement / motivation: the agreed list's item 2. `chat.messages` could only return the last 100 messages and counted the offset backwards from the newest, so an extension could not walk a long conversation or find a message. The world-book reader already had a page object; chat was the inconsistent one.
- Stage: branch `feature/chat-paging-and-external`, first batch.

## Breaking change (recorded deliberately)

`chat.messages` now returns a page object instead of a bare array:

```json
{ "total": 120, "offset": 0, "limit": 20, "hasMore": true, "messages": [ ... ] }
```

`offset` also changed meaning: it is now an **absolute start index from the beginning of the chat** rather than "skip N from the newest", so a caller can traverse the whole log. The tail is `offset = total - limit`, or `order: 'newest'` to walk backwards. All in-repo call sites (the harness) were migrated in the same commit; the API index marks the change.

## Changes

- `limit` raised to 1–200 (was 1–100), default 20.
- `query` (≤ 200 chars) matches message text case-insensitively; `total` reports the **match count**, and each returned message keeps its absolute `index`, so a filtered list can still address the original position.
- `order: 'oldest' | 'newest'` controls traversal direction while keeping absolute indexes.
- An offset past the end is an empty page with the correct `total`, not an error.
- Text is still truncated at 2000 characters with `truncated: true`, and no host object is leaked (`extra` etc. stay out).

- `npm run verify:browser`: **197/197 checks pass** (three consecutive runs).

## Risks / outstanding

- Search is a linear scan over the in-memory chat on each call; fine for local reads, and no index is kept.
- Paging is index-based with no revision token: a message inserted between two pages shifts the window (same caveat as world entries).
- `order: 'newest'` reverses the match order, so `offset` semantics differ between orders; documented but worth care.
